# Stream-Radius — لوحة إدارة المشتركين (نسخة للواجهة)

نسخة من كود لوحة Stream-Radius (إدارة مشتركين PPPoE على FreeRADIUS) لشغل الواجهة (front end).
مفيهاش أي بيانات حقيقية: لا مشتركين ولا معاملات ولا عناوين سيرفرات.

## فتح اللوحة ببيانات وهمية (من غير سيرفر)
افتح `app/web/index.html` في المتصفح (دبل كليك). وضع التجربة بيشتغل لوحده، وكل الصفحات بتشتغل ببيانات متألّفة من `app/web/demo.js` (علامة برتقالي تحت «وضع تجربة — بيانات وهمية»).
- أو شغّل أي سيرفر ملفات على فولدر `app/web` وافتح `index.html?demo`.
- `?demo&mode=live` يوري شكل وضع التشغيل (Live).
- التعديلات اللي تعملها جوه اللوحة بتتمسح لما تعمل Reload، والخطوط والأيقونات محتاجة إنترنت.

## الملفات
- `app/web/` — الواجهة كلها (HTML / CSS / JavaScript عادي، من غير أي framework). كل صفحة ليها ملف: `subscribers.js`، `cash.js`، `dashboard.js`…
  - `app.js`: الأساسيات (`api()`، القايمة، `modal()`، `toast()`)، و`app.css`: الشكل كله.
  - `i18n.js` / `i18n-en.js`: النصوص (عربي / إنجليزي).
- `app/*.go` — السيرفر (Go + MariaDB). مش محتاجه عشان تعدّل الواجهة.

## قواعد للتعديل
- الواجهة بتكلم السيرفر بـ `api("path")` بس؛ ما تغيّرش أسماء الحقول اللي جاية من السيرفر.
- ما تضيفش مكتبات أو سكريبتات جديدة من مواقع بره، وممنوع أي كود يبعت بيانات لأي مكان.
- `demo.js` للتجربة بس؛ ما تعدّلش عليه عشان تخلّي صفحة تشتغل — عدّل الصفحة نفسها.
- اللوحة عربي (RTL) وبتتفتح على الموبايل كتير: لازم كل صفحة تبان كويس على شاشة صغيرة.
